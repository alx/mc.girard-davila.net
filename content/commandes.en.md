## Navigation

| Command | Effect |
|---|---|
| `/lobby` | Return to the hub from any world (aliases `/hub`, `/spawn`) |
| `/ob leave` | Leave your OneBlock island and return to the hub. |

> The coloured hub gates also lead to each world (BedWars, OneBlock, Parkour, Creative, Flat).

## OneBlock (`/ob`)

| Command | Effect |
|---|---|
| `/ob join` (or `/ob j`) | Join a new island or your own. |
| `/ob leave` | Return to the hub. |
| `/ob invite <player>` | Invite a friend to your island (multiplayer). |
| `/ob accept` | Accept a received invitation. |
| `/ob kick <player>` | Remove a guest from your island. |

> **Respawn** : in the OneBlock world, `keep-inventory` is enabled and DeathRespawn is disabled — you keep your items on death.

## BedWars (`/bw`)

| Command | Effect |
|---|---|
| `/bw join <arena>` | Join a game. Arenas: `bedwars1`, `bedwars2`, `bedwars3` (Red vs Blue) and `bedwars3p` (3-player 1v1v1). |
| `/bw leave` | Leave the current game. |
| `/bw rejoin` | Rejoin the latest game. |
| `/bw autojoin` | Join the first waiting game. |
| `/bw stats [player]` | Show your stats (or another player's). |

## Parkour (`/pa`)

| Command | Effect |
|---|---|
| `/pa join parkour1` | Start the timed course. |
| `/pa leave` | Leave the course. |
| `/pa stats` | View your course stats. |
| `/pa list` | List available courses. |

## Deaths & respawn (DeathRespawn)

| Command | Effect |
|---|---|
| `/tpdeath [player]` | Teleport to the last death location (yours, or another player's). |
| `/deathloc clear` | Show or clear the saved death location. |

## Skins (offline accounts)

| Command | Effect |
|---|---|
| `/skin <name>` | Apply the skin of a Minecraft name. |
| `/skin clear` | Remove the applied skin. |

## WorldEdit (creative worlds only)

Tip: select an area with the wand (`//wand`) then apply an action.

| Command | Effect |
|---|---|
| `//wand` | Get the selection wand. |
| `//set <block>` | Fill the selection with a block. |
| `//copy` / `//paste` | Copy then paste a selection. |
| `//undo` / `//redo` | Undo / redo the last action. |

> WorldEdit is only usable in the **creative** worlds (`creative` and `flatland`).
