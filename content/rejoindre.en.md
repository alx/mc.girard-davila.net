## From the local network (LAN)

1. Launch **Minecraft Java Edition** (any recent version — older clients also work thanks to ViaVersion/ViaBackwards).
2. Multiplayer → **Add Server** →
   - Name: `New World`
   - Address: `192.168.1.109:25565`
3. The server also appears in the **LAN** tab (thanks to LANBroadcaster).

## Account

The server is in **offline mode**: no Microsoft account needed. A launcher that supports offline / Ely.by accounts (e.g. **PineconeMC**, a Prism Launcher fork) works great.

## First visit

- Press **Enter** in the hub, then take a **portal**.
- `/lobby` to return to the hub.
- Minigames: `/bw join <arena>`, `/ob join`, `/pa join parkour1`.

> 🔒 Public address (`mc.girard-davila.net`): **coming later** — the server is currently accessible on the local network only.
