## Depuis le réseau local (LAN)

1. Lancez Minecraft **Java Edition** (n'importe quelle version récente : le serveur accepte aussi les anciens clients grâce à ViaVersion/ViaBackwards).
2. Multijoueur → **Ajouter un serveur** →
   - Nom : `New World`
   - Adresse : `192.168.1.109:25565`
3. Le serveur apparaît aussi dans l'onglet **LAN** (grâce à LANBroadcaster).

## Compte

Le serveur est en mode **hors-ligne** : pas besoin de compte Microsoft. Un lanceur compatible comptes hors-ligne / Ely.by (par ex. **PineconeMC**, un fork de Prism Launcher) fonctionne très bien.

## Première visite

- Appuyez sur **Entrée** dans le hub puis empruntez un **portail**.
- `/lobby` pour revenir au hub.
- Mini-jeux : `/bw join <arène>`, `/ob join`, `/pa join parkour1`.

> 🔒 Adresse publique (`mc.girard-davila.net`) : **à venir** — le serveur est pour l'instant accessible uniquement sur le réseau local.
