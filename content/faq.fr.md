### Le serveur est-il public ?
Pas encore — il est accessible uniquement sur le réseau local pour le moment. Une adresse publique viendra plus tard.

### Faut-il payer Minecraft ?
Non ; le serveur est en mode hors-ligne, un compte hors-ligne (ou Ely.by) suffit pour jouer.

### Comment être prévenu·e des LAN parties ?
Inscrivez votre email via le formulaire en haut de la page d'accueil.

### Quelles données collectez-vous ?
Uniquement l'email (et éventuellement pseudo/message) que vous saisissez dans le formulaire d'inscription, dans le seul but de vous recontacter pour les LAN parties. Désinscription sur simple demande.

### Puis-je utiliser WorldEdit ?
Oui, dans les deux mondes **créatifs** (commande `//wand`).
